## 启动方式

业务上不再区分运行时在线/离线模式：

- 设备智能体未启动时，设备就是离线。
- 设备智能体通过 `main.py` 启动后，设备就是在线接入状态。

生产启动方式：

```bash
python3 /home/lx/dev_ws/src/device_agent/main.py
```

本地调试启动方式：

```bash
python3 /home/lx/dev_ws/src/device_agent/main.py --debug
```

`--debug` 只是本地调试输入源，终端提示为 `用户:`，用于调试、测试和本地控制；它不是业务离线状态。
agent 不要通过自然语言调用 CLI 切换在线/离线。

/home/lx/dev_ws/src/device_agent/.venv/bin/python src/device_agent/main.py --virtual-devices
