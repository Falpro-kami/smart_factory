# ur10e_2f85_mujoco

Standalone MuJoCo bringup package for a UR5e arm with Robotiq 2F85 gripper.

Launch:

```bash
ros2 launch ur10e_2f85_mujoco bringup.launch.py
```

Headless:

```bash
ros2 launch ur10e_2f85_mujoco bringup.launch.py headless:=true
```

With RViz:

```bash
ros2 launch ur10e_2f85_mujoco bringup.launch.py rviz:=true
```
